Workshop & Educational Use

This package is designed for Agents Hunting Agents workshops hosted by the AI Cyber Alliance. It is also openly available for community members, educators, and security practitioners to teach, practice, and learn hands-on cyber hunting techniques.

What's Included

The archive contains realistic, fictionalized investigation datasets complete with multi-source telemetry, scenario briefings, network maps, and investigation clues:

  • 6 Hands-On Scenarios: Self-contained incident investigations ranging from credential exposure and compromised MCP tooling to malicious agent behavior and rogue service impersonation.
  • Diverse Telemetry: Multi-layer log artifacts including Zeek logs (DNS, HTTP, Conn, SSL), internal DNS queries, host EDR event streams (JSONL), firewall logs, NetFlow CSV records, and application audit trails.
  • Investigation Artifacts: Architecture diagrams, network maps, asset inventories, support tickets, and scenario briefings.
  • Timeline Correlation Tool: A standalone Python utility (tools/timeline.py) that parses and merges multi-format logs into chronological order with timezone-aware alignment.
